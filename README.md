# NewCode

A browser Pong game with progressive difficulty levels.

## Level flow
- **Level 1**: first to **3** points, but if the CPU scores even **1** point, Level 1 resets.
- **Level 2**: random square obstacles are added to the court and can deflect the ball.
- **Level 3**: paddles can move in 2D (`W/A/S/D` or arrow keys).
- **Level 4**: a slow red death ball bounces around and kills the player on contact.
- **Level 5**: the AI gets a second paddle.

## Run locally
Open `index.html` in any modern browser.
